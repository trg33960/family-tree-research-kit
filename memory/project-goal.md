This project turns a template (`index.html`) into an interactive, well-sourced family tree for the user's own family: a pan/zoom board of person cards with dossiers, a Stories panel, a Migrations timeline, and a globe of birthplaces and migration routes. The page is self-contained and deployed as a public static site.

Start from the user's known direct line, then research outward, citing every fact. See [[sourcing-standards]], [[privacy-living-people]], and [[data-model-contract]].
